Keyboard shortcuts

Yen Studio's keys follow FL Studio's wherever it has them. The keys of the window in front come first: the Piano roll's D is its Delete tool, and the Playlist's is too. Keys that work everywhere are listed first.

⌘ and Ctrl both work for command keys, so ⌘Z is also Ctrl+Z. Where a key must be Ctrl, it says so. Keys on the number pad say "Numpad".

Menus show their keys beside their items, and buttons show theirs when you hold the pointer over them.

Everywhere

These work whichever window is in front, and from your plugins' own windows too, when the plugin doesn't use the key itself.

Play and record

Key What it does

L Switch between pattern mode and song mode
R Turn recording on or off
Numpad + Next pattern (past the last, a new one)

⌘T Play notes from the computer's keyboard: see The typing keyboard

The typing keyboard

Press ⌘T, or choose View › Typing Keyboard to Piano, to play the selected channel from the computer's keyboard. Press it again to stop. See MIDI keyboards.

Keys Notes
Z X C V B N M , . / White keys, from C
S D G H J L ; Black keys of that octave
Q W E R T Y U I O P White keys, an octave up
2 3 5 6 7 9 0 Black keys of the octave up
[ / ] Octave down / up

While it's on, the other letters and digits do nothing, so a stray key doesn't switch tools. Keys with ⌘, Ctrl or ⌥ still work, and so does Space.

Text fields and the assistant

In the assistant's message box, Enter sends, ⇧Enter starts a new line, and Esc leaves the box. In the model menu, ⌘1 … ⌘9 pick a model, and the arrows and Enter move and choose.

While you type in any text field, the keys above type text instead.
