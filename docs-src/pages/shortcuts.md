Yen Studio's keys follow FL Studio's wherever it has them. The keys of the window in front come first: the Piano roll's
<kbd>D</kbd> is its Delete tool, and the Playlist's is too. Keys that work everywhere are listed first.

⌘ and Ctrl both work for command keys, so <kbd>⌘Z</kbd> is also Ctrl+Z. Where a key must be Ctrl, it says so. Keys
on the number pad say "Numpad".

Menus show their keys beside their items, and buttons show theirs when you hold the pointer over them.

## Everywhere

These work whichever window is in front, and from your plugins' own windows too, when the plugin doesn't use the key
itself.

### Play and record

| Key | What it does |
| --- | --- |
| <kbd>Space</kbd> | Play or stop. While the Browser previews a sound, stops the preview |
| <kbd>L</kbd> | Switch between pattern mode and song mode |
| <kbd>R</kbd> | Turn recording on or off |
| <kbd>Numpad +</kbd> | Next pattern (past the last, a new one) |
| <kbd>Numpad −</kbd> | Previous pattern |
| <kbd>⌘T</kbd> | Play notes from the computer's keyboard: see [The typing keyboard](#the-typing-keyboard) |

## The typing keyboard

Press <kbd>⌘T</kbd>, or choose **View › Typing Keyboard to Piano**, to play the selected channel from the computer's
keyboard. Press it again to stop. See [MIDI keyboards](midi).

| Keys | Notes |
| --- | --- |
| <kbd>Z</kbd> <kbd>X</kbd> <kbd>C</kbd> <kbd>V</kbd> <kbd>B</kbd> <kbd>N</kbd> <kbd>M</kbd> <kbd>,</kbd> <kbd>.</kbd> <kbd>/</kbd> | White keys, from C |
| <kbd>S</kbd> <kbd>D</kbd> <kbd>G</kbd> <kbd>H</kbd> <kbd>J</kbd> <kbd>L</kbd> <kbd>;</kbd> | Black keys of that octave |
| <kbd>Q</kbd> <kbd>W</kbd> <kbd>E</kbd> <kbd>R</kbd> <kbd>T</kbd> <kbd>Y</kbd> <kbd>U</kbd> <kbd>I</kbd> <kbd>O</kbd> <kbd>P</kbd> | White keys, an octave up |
| <kbd>2</kbd> <kbd>3</kbd> <kbd>5</kbd> <kbd>6</kbd> <kbd>7</kbd> <kbd>9</kbd> <kbd>0</kbd> | Black keys of the octave up |
| <kbd>[</kbd> / <kbd>]</kbd> | Octave down / up |

While it's on, the other letters and digits do nothing, so a stray key doesn't switch tools. Keys with ⌘, Ctrl or ⌥
still work, and so does <kbd>Space</kbd>.

## Text fields and the assistant

In the [assistant](assistant)'s message box, <kbd>Enter</kbd> sends, <kbd>⇧Enter</kbd> starts a new line, and
<kbd>Esc</kbd> leaves the box. In the model menu, <kbd>⌘1</kbd> … <kbd>⌘9</kbd> pick a model, and the arrows and
<kbd>Enter</kbd> move and choose.

While you type in any text field, the keys above type text instead.
